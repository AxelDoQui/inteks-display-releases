Seguridad y acceso

Contraseña del panel y token para la extensión de Chrome. El PIN de emparejamiento de pantallas es aparte.

Pega este token en la configuración de la extensión para que pueda enviar tipos de cambio de forma segura.

Cómo usar

Conectar pantallas

1. Ejecuta python server.py en el portátil

2. En cada tablet abre Chrome con un nombre único:

http://IP:8080/player.html?screen=pantalla1
http://IP:8080/player.html?screen=pantalla2

3. Para girar la pantalla añade &rotation=90 (0, 90, 180 o 270):

http://IP/player.html?screen=pantalla3&rotation=90
